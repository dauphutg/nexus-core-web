隱私權政策

我們盡可能少蒐集資料。本頁清楚說明我們保留哪些資料，以及您如何刪除。

一、瀏覽網站

您無須帳號、無須提供任何個人資料，即可閱讀所有計畫、成績紀錄與文章。

我們以不使用 Cookie 的方式統計瀏覽次數：每個瀏覽器工作階段計一次，記錄頁面、語言、來源網站，以及是否使用已安裝的 App。我們不儲存您的 IP 位址，也不會為您建立識別碼。

本站亦使用 Cloudflare Web Analytics，以不使用 Cookie、不跨站追蹤的方式統計頁面載入。

二、您裝置上的設定

您的瀏覽器會在您自己的裝置上記住語言、亮色或暗色主題，以及通知語言（本機儲存）。這些資料不會離開您的裝置，您可隨時在瀏覽器設定中清除。

三、通知

開啟通知時，您的瀏覽器會提供此裝置的推播位址。我們會連同您的語言、開啟通知的頁面與您得知本站的管道一併保存，僅用於在新計畫發布時通知您。

在網站上點選「關閉通知」，或在瀏覽器中封鎖通知後，該推播位址即失效，我們會將其刪除。

四、電子郵件名單

加入電子郵件名單或訊號候補名單時，我們會保存您的電子郵件，以及語言、登記頁面與您得知本站的管道。電子郵件僅用於寄送計畫、NEXUS CORE App 與訊號的消息，您可隨時要求刪除。

我們絕不會將您的電子郵件出售、出租或提供給券商、廣告商或任何第三方。

五、資料存放位置

本網站透過 GitHub Pages 與 Cloudflare 提供服務；通知、電子郵件名單與瀏覽統計存放於 Cloudflare。這些服務商代我們處理資料，並可能將資料存放於您所在地以外的地區。

六、保存期間

推播位址保存至您關閉通知或位址失效為止；電子郵件保存至您要求刪除或名單關閉為止。瀏覽統計不含個人資料，僅以總數保存。

七、您的權利

您可以要求查詢、更正或刪除我們所保存關於您的資料。依您所在地的個人資料保護法規，您可能享有其他權利。

如需提出請求，請透過我們的 Telegram 頻道聯繫，我們會在 30 天內回覆。

八、未成年人

NEXUS CORE 不適用於未滿 18 歲者，我們不會在知情的情況下蒐集兒童的資料。

九、政策修訂

本政策如有修訂，我們會更新頁首日期。
